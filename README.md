Pizza Oven Mobile is a mobile patch applicator inspired by [Pizza Oven+ by SurfyCrescent97](https://gamebanana.com/tools/21866) and [Pizza Oven by Tekka](https://gamebanana.com/tools/12625), designed to apply xdelta mods directly on Android devices.
</center>

## FEATURES
> Native xdelta patch application on Android  
> Simple file picker interface for game base files and mod patches  
> Fast background processing  
> No PC required for patching `.xdelta` files  

## ABOUT THE PROJECT
This project adapts the core mod-patching capabilities of Pizza Oven for Android environments using Kotlin and native C++ xdelta3 processing.
